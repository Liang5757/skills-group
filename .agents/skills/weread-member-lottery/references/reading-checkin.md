# 书架阅读签到与进度恢复

仅通过 `mcp__cua_repl.js` 操作本地 App，复用当前 `weread` 连接。每次动作后读取新 AX；只输出简短结果，正文锚点保留在会话内，不写入仓库。验证文档和测试样例使用虚构数据，不保存真实书名、阅读日期、进度、正文或账户截图。

## 打开并记录

1. 从当前页返回主界面：关闭已观察到的普通弹窗，再使用当前 AX 的返回按钮。抽奖页常见 `id_navigation_bar_back_button`，阅读器是 `BackButton`。不要点击 macOS 关闭按钮。选书架标签 `id_home_tab_shelf`；已在书架则跳过。
2. 在书架的书籍容器中选一本可读文字书。任意书时优先当前可见、已有进度的书；用户指定书则按书名选择。书名 `Description` 可能有前导空格，比较前先 trim。不要把排序按钮或书架容器的「下一页」当成阅读翻页。
3. 打开后确认 `WRPageView` 正文。记录书名、章节、页码截图及原页完整 AX 正文 `originalText`。可用以下函数读取正文，随后保持窗口大小、字体和翻页方式不变：

```javascript
var pageText = state => state.match(
  /(?:^|\n)[\t ]*\d+ element ID: WRPageView,[^\n]*Value: ([\s\S]*?)(?=\n[\t ]+\d+ (?:element|container|按钮|返回按钮|关闭按钮|全屏幕按钮|最小化按钮|文本栏|文本|标签)(?=[ ,\n]|$)|\n\d+ menu bar\b|$)/
)?.[1];
var initial = await weread.getAXStateAndScreenshot({disableDiffing:true, emit:false});
var originalText = pageText(initial.state);
if (!originalText?.trim()) throw new Error('缺少原页正文，不能开始翻页');
var visited = [originalText];
if (initial.screenshot) await nodeRepl.emitImage(initial.screenshot);
// 根据返回的截图确定正文左右翻页区与原页位置。
```

正文边界按 AX 缩进、元素索引及控件类型识别，不能仅凭数字开头截断正文。若遇到未识别的 AX 格式或疑似控件文本混入锚点，先核对截图，不使用该锚点判定恢复成功。

缺少文字锚点、遇到漫画/PDF、试听、登录或付费界面时，不改变进度；可返回书架换一本可读文字书，最多换一次。若有进度同步弹窗，先明确哪个位置是原位置，不能替用户选择覆盖。

## 翻阅

- 默认最多翻 3 页，每个新页真实停留 3 秒；用户指定页数或时长时按要求执行。停留可以用 `clock.sleep`，这段时间单独计入阅读耗时，不是等待界面加载。不为追求签到结果反复长时间刷页。
- 先基于当前截图确定正文左右翻页区域。每次只点击一次，读取完整 AX，确认正文变化后才计为一次翻页，并保存该页正文到 `visited`。靠近书末可向前文翻；到边界时少翻几页即可。不得点击「标记读完」、推荐书、评论或购买入口。
- **不要直接信任原生 Secondary Actions 的方向名称。** 本机实测 `WRPageView` 的「上一页」动作反而向后文推进；采用截图定位的左右正文点击区，并核对实际方向。坐标按本次截图选择，不复制历史窗口坐标。
- 页码可能因重新排版而变化；正文才是恢复依据。相同正文不计数、不重试连点。若正文消失、方向异常、出现弹窗或操作报错，停止继续阅读并进入恢复步骤。对结果不确定的一次点击，先观察实际正文，确认是否移动，不能直接将点击次数当成移动页数。

## 恢复与验证

1. 按已确认的实际方向反向逐页返回。每次读取正文，与 `visited` 的上一项比对；匹配才继续回退，直到与 `originalText` 完全一致。不论正常结束还是异常中断，都优先恢复；不能因阅读计时结束跳过此步骤。
2. 若反向一步不符合预期，停止盲目翻页，用截图核对遮挡、方向和章节。优先用已观察到的阅读器返回原位置功能；只有确实显示该功能时才能点击。否则可通过目录回到已记录章节，再有界定位原文。最多额外定位 6 页，仍无法确认则明确报告「未确认恢复」及原章节/锚点，不声称成功。
3. 正文精确匹配后，点正文中央唤出工具栏，再点当前 `BackButton` 返回书架；按已记录书名重新打开，核对正文仍与 `originalText` 一致。此时才报告「原阅读位置已恢复」，默认停留在原页。书架顺序可能变化，重新查找书名，不复用旧索引。
4. 若出现明确的「签到成功／今日已签到」状态，可据此报告；否则报告「已翻阅 N 页并恢复原位置，签到状态未确认」。不要把阅读累计时长、最大阅读百分比或已读天数的猜测当成签到凭据；恢复的是当前阅读位置，不会撤销本次累计阅读记录。

## 本机验证

已验证翻页后可通过正文左侧逐页返回，完整原页正文匹配；退出书籍并重新打开后再次匹配。实测页码可能重新计算而正文不变，因此不能仅比较页码。此验证覆盖翻页与进度恢复，未确认签到成功，也不证明固定停留时长能满足签到规则。
