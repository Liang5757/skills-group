# 微信读书会员抽奖与阅读签到

通过 `mcp__cua_repl.js` 操作本机已登录 App。只要求抽奖时，目标是在 30 秒内完成目标按钮点击；每次最多点击一次，不等待中奖弹窗、奖励数字或到账结果。仅查状态时不发起抽奖。

## 选择流程

- 只要求抽奖：执行下方抽奖流程，点击后结束。
- 要求签到、阅读或翻页后恢复进度：连接 App 后按 [阅读签到步骤](references/reading-checkin.md) 执行，不额外抽奖。
- 同时要求抽奖和签到：先完成抽奖阶段，再执行阅读阶段；下方的「点击后结束」仅指抽奖阶段。若抽奖需用户接管，保留说明，仍可完成已授权的阅读步骤。

阅读默认翻阅最多 3 页、每页停留 3 秒，再恢复原页。仅在明确看到签到成功状态时报告签到成功；翻页动作不等于服务端已记入签到。阅读的停留及恢复核验单独计时，不能套用抽奖的 24.5 秒实测结论。

## 快速执行

抽奖默认只读取本文件，不加载长脚本、不探索已知入口。执行时不查仓库、不跑测试、不改 skill。

1. 首次 CUA 调用只执行 `var weread = await cua.getApp("com.tencent.weread")` 并阅读工具说明。若错误列出唯一 `Wrapper/WeRead.app` 路径，下一调用按该路径连接；不要逐个试应用名或缓存临时路径。其他启动错误才读取 [scripts/connect.js](scripts/connect.js) 的有界重连函数。
2. 首页有「福利场」时，连接语句与下面的短片段放在同一次 CUA 调用中。每一步仍读取最新 AX，仅点击唯一匹配；已中奖入口只用于查看结果。不要扩写为通用框架。

```javascript
var state = await weread.getAXState({disableDiffing:true, emit:false});
var clickedTarget = false;
for (var pattern of [/Description: 福利场(?:\s|,)/, /Description: 每日抽奖,/, /Description: 你已中奖/]) {
  var rows = state.split('\n').filter(row => pattern.test(row));
  if (rows.length !== 1) break;
  await weread.click(Number(rows[0].match(/^\s*(\d+)/)[1]));
  if (pattern.source.includes('你已中奖')) clickedTarget = true;
  state = await weread.getAXState({disableDiffing:true, emit:false});
}
nodeRepl.write({clickedTarget, state});
```

3. `clickedTarget: true` 时立即结束，无需看到结果页；尚未点击目标按钮时只续接当前状态，不重跑上述片段。书架起点走「我 → 福利」；相应 ID 为 `id_home_tab_personal`、`id_cell_FreeCoin`。福利页选「会员抽奖」的「每日抽奖」。每次将 `click(当前索引)` 和 `getAXState()` 合并。读取会员抽奖按钮（ID `WRUI_Pressable_MembershipLottery-LotteryButton`），按下节处理。
4. 页面未加载时才用 `getAXStateAndScreenshot()` 定位入口，不重复点击。目标按钮点击调用成功后立即结束；若工具要求动作后读取 AX，合并一次 `getAXState()` 即可，不截图、不轮询、不关闭弹窗。

## 点击边界

- 明确是已有会员的免费机会、用户要求执行且当前工具允许时，点击抽奖按钮一次。若工具要求用户接管，说明限制；不换工具绕过。
- 「你已中奖 · 每日可抽」只能点击查看已有结果，反馈「已点击已有结果入口」，不能说成新抽了一次。明确「今日已抽／明日再来」时直接报告已抽过。
- 开通、续费、充值、书币／积分消耗、登录或验证码要求出现时停止并说明，不购买、不分享、不额外授权。
- 点击调用结果不确定或报错时，不自动重复点击，也不声称已完成。

只在用户另行要求查看奖励时，才读取结果或使用备用脚本；这些检查不属于本技能默认完成条件。

## 时限与异常

仅抽奖流程从开始读取技能计算总耗时，目标 30 秒内；约 20 秒仍在找入口时停止盲目探索并报告阻碍。不能每次回退重新计时。底层调用无法强制取消，登录、工具或网络延迟可能超时；如实报告，不以提前退出冒充完成。阅读开始后即使超时，也要优先恢复已记录的原位置。

正常运行无需长脚本。连接标识不匹配时才用 `cua.listApps()`；无法定位时基于当前截图处理。继续下一步操作前读取新 AX，索引不跨页面复用。抽奖阶段点击完成即结束，不重复测试、不自动创建定时任务。验证记录只保留操作结论和耗时，不将真实书名、阅读进度、操作日期时间、奖励数额、账户截图、凭证或本机用户路径写入仓库；测试使用虚构数据。

抽奖阶段只报告「已点击抽奖按钮」「已点击已有结果入口」或具体阻碍；不把点击完成写成抽中奖励。阅读阶段报告实际翻页数、是否恢复原位置及签到状态是否确认。报告耗时时说明计时范围。开发／校验耗时与日常运行耗时分开。
