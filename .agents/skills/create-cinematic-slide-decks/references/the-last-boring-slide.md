## Reusable storyboard

| Scene | What the audience sees | What changes |
| --- | --- | --- |
| Baseline | A flat chart with a readable axis and clear units | The audience learns what the marks represent. |
| Threshold | A point approaches a visible limit or crosses a labeled threshold | The presenter advances once the threshold is understood. |
| Reveal | The chart extends and the camera or layout pulls back while the same point remains visible | The surrounding space makes the new scale legible. |
| Implication | A stable view shows the original baseline, the new extent, and the takeaway | The audience can read the result without replaying the animation. |

For a capacity-planning talk, use a single line to show queue depth and a horizontal line to show a known operating limit. As the data crosses the limit, extend the chart into the range the initial view could not show. Keep the limit and the same point labeled as the framing changes. Use the final view to explain when additional capacity is needed.
